# surveil-core

Shared library used by both `backend/` (FastAPI, Azure Container Apps) and
`function/` (Azure Function analysis worker) so detection, alert-rule, and
notification logic is written exactly once.

Installed by:
- `backend/Dockerfile` (`pip install ./shared`)
- `src/surveil_deploy/steps/s07_deploy_function.py`, which vendors a copy of
  `surveil_core/` into `function/` before `func azure functionapp publish`
  (Azure Functions remote build only sees files inside the function app's own
  deployment package, so the shared package can't be referenced by a relative
  path outside it — see `docs/architecture.md` for the full rationale).

Do not edit generated copies under `function/surveil_core/` — that directory
is regenerated by the deploy pipeline and is gitignored.
